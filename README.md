# 🌐 Ala'a Frihat - Personal Portfolio

A sleek, responsive, and modern developer portfolio website showcasing my software development projects, experience, technical skills, and career transition.

---

## 📌 Features

- **Responsive Navigation Bar**: Includes custom gradient design and interactive smooth links to different sections.
- **Hero Section**: Highlights my background as a former Agricultural Engineer and Bodybuilding Coach turned Software Developer Trainee at Orange Coding Academy.
- **About Me & Experience**: Displays detailed insights into my education, training, and current development track.
- **Skills & Competencies**: Categorized technical stack (HTML5, CSS3, Bootstrap 5, Flexbox & Grid, Git/GitHub) and key soft skills.
- **Featured Projects**: Interactive display cards showcasing projects with links to GitHub repositories.
- **References & Contact Details**: Section listing trainers and manager contacts along with direct social links.

---

## 🛠️ Technologies Used

- **HTML5**: Semantic web markup.
- **CSS3**: Custom styling, Flexbox, CSS Grid, and custom color gradients.
- **Bootstrap 5**: Responsive layout grid and components.
- **Google Fonts**: *Plus Jakarta Sans* typography.
